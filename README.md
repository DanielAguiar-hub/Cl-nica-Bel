## 🚀 Funcionalidades

- **Navegação Inteligente (Smooth Scroll):** Transições suaves de rolagem de página ao clicar nos links do cabeçalho.
- **Menu Hambúrguer 100% Puro CSS:** Menu interativo responsivo para dispositivos móveis implementado sem JavaScript, utilizando a técnica do *Checkbox Hack*.
- **Visual Premium e Minimalista:** Paleta de cores harmoniosa baseada em tons de azul ciano e verde esmeralda, com tipografia moderna (Montserrat e Inter).
- **Micro-interações Suaves (Efeitos de Hover):**
  - Cards de serviços que se deslocam tridimensionalmente (`translateY`) e ganham sombras profundas ao passar o mouse.
  - Links e ícones sociais com efeitos de transição de cor e movimento.
  - Botões principais com destaque de profundidade dinâmico.
- **Totalmente Responsivo:** Layout adaptável para smartphones, tablets e desktops (Mobile-First / Relação de Aspecto Flexível).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de elementos (header, main, section, footer).
- **CSS3:**
  - Layouts modernos com **Flexbox** e **CSS Grid**.
  - Variáveis nativas do CSS (`:root`) para consistência de design system.
  - Animações e transições fluidas (`transition`, `transform`).
  - Responsividade robusta com `@media` queries.
  - Reset de estilos nativos (`reset.css`).
